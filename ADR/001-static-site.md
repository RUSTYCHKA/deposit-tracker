# ADR-001 Static Site Architecture

## Status

Accepted

## Context

Проект должен размещаться бесплатно и не требовать серверной инфраструктуры.

## Decision

Использовать статическую генерацию и GitHub Pages.

## Consequences

+ Бесплатный хостинг
+ Простая поддержка
+ Высокая скорость

- Нет серверной логики
