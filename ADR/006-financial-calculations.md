# ADR-006 Financial Calculations

## Status

Accepted

## Context

Проект должен корректно рассчитывать доходность банковских продуктов,
включая капитализацию, ступенчатые ставки и влияние инфляции.

## Decision

Все финансовые расчёты выполняются на Python data pipeline.

Для денежных и процентных расчётов используется Decimal вместо float.

Основные показатели:

- nominal rate;
- effective rate;
- real rate;
- final balance;
- earned interest.

## Principles

Рекламная ставка не считается фактической доходностью продукта.

Для продуктов со ступенчатыми ставками эффективная доходность
рассчитывается на основании всех периодов ставки.

Реальная доходность рассчитывается с учётом инфляции.

## Consequences

### Positive

- Единая реализация финансовой математики.
- Возможность покрыть расчёты тестами.
- React получает уже рассчитанные данные.
- Исключаются ошибки JavaScript floating-point arithmetic.

### Negative

- Часть бизнес-логики находится в Python pipeline.
- При изменении алгоритмов необходимо обновлять generated data.
